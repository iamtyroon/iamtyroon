# Hi, I'm Tesfaalem

I make cool shit from Nairobi, Kenya — mostly AI tooling and small, complete products.

- **[songle](https://github.com/iamtyroon/songle)** — daily music guessing game. Hear widening snippets, name the track before the day ends.
- **[agent-setup](https://github.com/iamtyroon/agent-setup)** — one installer that reproduces my whole AI dev environment on any machine.
- **[airstem](https://github.com/iamtyroon/airstem)** — play a separated song with your hands. Four fingers mix four stems, thumb controls pitch.

## Things I've built

| Project | What it is |
|---|---|
| [songle](https://github.com/iamtyroon/songle) | Heardle-style daily music game. React, Vite, Tailwind, Firebase. iTunes audio previews, atomic-score leaderboards, multi-provider auth. |
| [agent-setup](https://github.com/iamtyroon/agent-setup) | Portable AI-agent setup for Claude Code, Codex, OpenCode and Antigravity. Vendored skills, portable config, idempotent installer. |
| [airstem](https://github.com/iamtyroon/airstem) | TouchDesigner stem player. MediaPipe hand tracking over webcam → OSC → Demucs stems (vocals/drums/bass/other). Left thumb = volume, right thumb = ±12 semitones. |
| [imvo](https://github.com/iamtyroon/imvo) | Text prompt → generated 2D image → interactive Three.js voxel scene, using Gemini's multimodal reasoning. |
| [jc4-mod-maker](https://github.com/iamtyroon/jc4-mod-maker) | GUI for building Just Cause 4 vehicle mods. Silent Protato/EasiEdit conversion, focused XML editor for performance tuning. |
| [codex-chat-organizer](https://github.com/iamtyroon/codex-chat-organizer) | Organizes local Codex chat history into project sections with objective-first titles. |
| [readme-gen](https://github.com/iamtyroon/readme-gen) | Scans a local repo and generates a real README from its manifest files. |
